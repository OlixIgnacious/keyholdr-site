Mac API key managers compared (2026): Keyholdr, Fidelius, EnvVault, 1Password CLI and more

There are now half a dozen small Mac apps that keep API keys in the macOS Keychain instead of .env files. They look alike in screenshots but differ in the things that matter day to day: whether they work in the terminal, whether a key reaches only the command that needs it, how often they ask for Touch ID, and whether your keys leave the Mac.

Ashwini Sharma · 24 November 2026 · updated 25 November 2026 · 9 min read

Short answer: for most developers who want their keys in both the menu bar and the terminal, Keyholdr is the simplest fit: it's free, runs on macOS 13 and later, asks for Touch ID on every read, and keyholdr run hands a key to one command instead of your whole shell. Pick Fidelius if you need per-project values synced to several Macs, Secret Store for keys on your iPhone too, EnvVault if your workflow still revolves around .env files, and the 1Password CLI if your team already pays for 1Password.

A note on bias: I make Keyholdr, so read this with that in mind. Every fact about another app below comes from that app's own website or store listing as of November 2026, and each one is linked. Where a listing doesn't say something, the table says "not stated" rather than guessing. If you make one of these apps and something is wrong or out of date, email me and I'll fix it.

Why "one command only" matters

Loading a key into your shell with export or eval is convenient, but every program you start from that shell afterwards inherits it: your editor's extensions, a dev server, package install scripts, and any AI agent working in that terminal. Handing the key to a single command (keyholdr run, accio, op run) means it exists only inside that process and disappears when it exits. It's the same reason keys in ~/.zshrc leak, and it's the biggest practical difference between these tools.

Keyholdr

Keyholdr is a menu bar app plus a keyholdr command that share one vault. Each key is its own macOS Keychain item.

  • Touch ID on every read, with no session mode. Copying from the menu bar, revealing a key, or reading one in a script always asks for Touch ID, Apple Watch or your password. There is no setting that unlocks keys silently for an hour.
  • Keys reach one command, not your shell. keyholdr run -e OPENAI_API_KEY=openai -- npm start injects the key into that process only. keyholdr env is there when you do want keys in the current shell.
  • A real terminal UI. Bare keyholdr opens a full-screen view to search, copy, add and delete keys. The CLI reads the Keychain directly, so it works even when the menu bar app isn't running.
  • Runs on more Macs. macOS 13 Ventura and later, the widest range of any app here, and Macs without Touch ID can use Apple Watch or the login password.
  • Moving Macs is covered. Export the vault to one passphrase-encrypted file (PBKDF2-SHA256 with 600,000 rounds, then AES-256-GCM) and import it on the new machine.
  • Rotation reminders. keyholdr list shows every key's age without reading a secret, and flags anything older than six months.
  • Tiny and private. About 700 KB of SwiftUI, opens with ⌃⌥⌘K from anywhere, no account, no network connections, and no data collected.

Trade-offs: no sync between Macs (deliberately), no .env import, no clipboard auto-clear yet, and keys are grouped by platform, label and tag rather than by project. The Mac App Store version's sandbox limits the CLI, so terminal users should install from Homebrew or the direct download.

Fidelius

Fidelius organizes keys by project, so DATABASE_URL can have a different value in each one. Its accio command runs a project's command with that project's keys injected, for example accio my-app npm run dev, and masks key values that show up in AI tools' output. It imports and exports .env files, keeps a Recently Deleted list, and clears copied values after 60 seconds.

Trade-offs: it costs from $24 (or a Setapp subscription) and needs macOS 15. Turning on its iCloud Keychain sync means your keys leave the Mac, end-to-end encrypted by Apple.

EnvVault

EnvVault is built around .env files. It imports .env, .env.local, .env.dev and .env.production, separates local, dev, staging and production environments, asks for confirmation on production values, and warns when an exported file isn't covered by .gitignore. It has a rotation and expiry dashboard and clears the clipboard after 30 seconds.

Trade-offs: $5.99, macOS 14+. Its listing doesn't mention a command-line tool or Touch ID, and its workflow still ends in exported .env files on disk.

Keyring Vault

Keyring Vault is a focused menu bar app: search, click to copy, keys grouped by project, Touch ID or your password when you open the vault, and the clipboard cleared after 30 seconds. It works fully offline.

Trade-offs: $4.99, macOS 15+, and no terminal tool of its own (it can import from a separate tokenvault CLI).

Secret Store

Secret Store is free and runs on Mac, iPhone and iPad. Every secret is an iCloud Keychain item, so it syncs across your Apple devices. It has no network access of its own, keeps copied values off Universal Clipboard, clears them after 90 seconds, and backs up to a passphrase-encrypted archive.

Trade-offs: keys always live in iCloud Keychain, and its listing doesn't mention a command-line tool. macOS 14.6+.

1Password CLI

If you already use 1Password, the 1Password CLI fits in. You put op://vault/item/field references in an env file and op run resolves them when the command starts, so the file itself holds no secrets. Keys sync to every device and teammate through your 1Password account.

Trade-offs: a paid subscription, a much larger app, keys stored on 1Password's servers (end-to-end encrypted), and Touch ID unlocks the CLI for a session rather than per read.

The built-in security command

Every Mac can already do the basics: security add-generic-password -a "$USER" -s openai -w saves a key, and security find-generic-password -a "$USER" -s openai -w reads it back. My guide to storing API keys on a Mac covers this approach in detail.

Trade-offs: items created this way don't ask for Touch ID, so any script running as you can read them, and there's no list, UI or rotation reminder.

How to choose

  1. Do you need keys in the terminal? If so, choose a tool with a real CLI: Keyholdr, Fidelius or the 1Password CLI. All three can hand a key to a single command.
  2. Should keys ever leave this Mac? If not, choose Keyholdr or Keyring Vault. If you want them on several devices, choose Fidelius or Secret Store (iCloud Keychain), EnvVault (iCloud) or 1Password.
  3. Do you want a prompt on every single read? Keyholdr always asks; the 1Password CLI unlocks for a session.
  4. Do AI agents run commands for you? With Keyholdr, every read an agent makes triggers a Touch ID prompt you can decline, and keyholdr run keeps the key out of the shell the agent works in.
  5. Which macOS are you on? Of the menu bar apps here, only Keyholdr runs on macOS 13 Ventura. EnvVault and Secret Store need macOS 14; Fidelius and Keyring Vault need macOS 15.
